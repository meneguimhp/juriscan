# Identidade Visual - Juriscan

## Arquivo oficial
- `logo-juriscan-light.svg` (uso em fundo claro)
- `logo-juriscan-dark.svg` (uso em fundo escuro)
- `logo-juriscan.svg` (base legado)
- `logo-juriscan-v1.svg` (variação alternativa)
- `logo-juriscan-v2.svg` (variação alternativa)

## Diretriz
Este arquivo é a fonte oficial de logo para:
- frontend
- materiais comerciais
- documentação

## Cores base da marca
- Azul ciano principal: `#20C7EB`
- Azul ciano secundario: `#149FCF`
- Azul de apoio (check): `#18AEDD`
- Texto primário: `#081A2D`

## Regras de uso
1. Não alterar proporção do logo.
2. Priorizar versão SVG.
3. Em fundo claro, usar `logo-juriscan-light.svg`.
4. Em fundo escuro, usar `logo-juriscan-dark.svg`.
5. No frontend, a troca é automática por `prefers-color-scheme` (tema do sistema).
